# Machine Learning Foundations

A structured, hands-on journey through numerical computing,
scientific visualization, and machine learning foundations.

## Current Focus

- NumPy: arrays, vectorization, matrix operations, and statistics
- Matplotlib: data visualization and statistical plots
- Jupyter Notebooks: executable examples and practical exercises

## Repository Structure

- `notebooks/01_numpy/` — NumPy practice
- `notebooks/02_matplotlib/` — Matplotlib practice
- `notebooks/03_numpy_matplotlib/` — Combined exercises
- `datasets/` — Practice datasets
- `outputs/` — Selected visualizations

## Tech Stack
